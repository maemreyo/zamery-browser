# Code of Conduct

Zamery Browser is intended to be a constructive, technically rigorous community. Participation in issues, discussions, pull requests, reviews, and other project spaces requires respectful and professional behavior.

## Expected behavior

- Focus criticism on ideas, code, behavior, and evidence rather than people.
- Be specific and constructive when reporting problems or reviewing contributions.
- Respect different levels of experience and give contributors room to ask questions and revise work.
- Protect privacy. Do not post credentials, private browser data, personal information, or security-sensitive material that should be handled through the private reporting process.
- Respect project scope and maintainer decisions even when you disagree; technical disagreement is welcome when expressed with evidence and without harassment.

## Unacceptable behavior

Harassment, threats, discrimination, personal attacks, deliberate humiliation, sexualized conduct, doxxing, spam, sustained disruption, and knowingly exposing another person's confidential or security-sensitive information are not acceptable.

## Enforcement

Maintainers may edit or remove content, close or lock discussions, reject contributions, or temporarily or permanently restrict participation when behavior violates this Code of Conduct. Enforcement decisions should be proportionate to the behavior and protect the ability of others to participate safely and productively.

If a conduct concern involves sensitive information, report it privately to the repository owner through GitHub rather than opening a public thread. Security vulnerabilities must use the process in [SECURITY.md](SECURITY.md).

By participating in this project, you agree to follow this Code of Conduct.
